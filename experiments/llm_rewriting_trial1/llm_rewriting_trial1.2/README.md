# Experiment: llm_rewriting_trial1.2

- **Goal**: Evaluate how LLM-rewritten text affects AV model performance.
- **Dataset**: Extracted 5 author samples, 1 article and 1 tweet for each author from CROSSNEWS Gold (Article + Tweet)
- **Modification**: rewriting style (**light** / medium / heavy)
- **Matching**:
	1.	article original – tweet original
	2.	article rewritten – tweet original
	3.	article original – tweet rewritten
	4.	article rewritten – tweet rewritten
